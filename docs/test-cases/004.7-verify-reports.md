# Test 004.7: Verify Reports After Macro Transactions

## Purpose

This test verifies that all financial reports (Balance Sheet, Income Statement, Swiss Balance Sheet, Swiss Income Statement, and Trial Balance) correctly reflect the state of the journal after all macro transactions from tests 004.1 through 004.9 have been executed.

**Note:** Tests 004.8 (TaxProvision) and 004.10 (LegalReserveAllocation) have been moved to [Test Case 007: Year-End Closing](./007-year-end-closing.md) since they are year-end closing entries, not regular macro transactions.

## Preconditions

See [PRECONDITIONS.md](./PRECONDITIONS.md) for general preconditions.

**CRITICAL:** This test case depends on:
- [Test Case 003](./003-record-initial-business-transactions.md) - Initial transactions recorded and **built-in report templates imported** (the "Import built-in report templates" scenario in test 003 must have run to make the report templates available in the dropdown)
- [Test Case 004.1](./004.1-test-macros.md) through [Test Case 004.9](./004.9-test-macros-tax-payment.md) - All macro transactions must have been executed

The built-in report templates (Balance Sheet, Income Statement, Swiss Balance Sheet, Swiss Income Statement, Trial Balance, etc.) are imported in test 003 via the "Import Built-in" menu button on the Reports page. This test selects those templates from the dropdown and generates reports; it does not re-import them.
