# Test Case 004.9: Test Macros - TaxPayment

**Feature:** Macro System - TaxPayment Macro  
**Date:** 2026-04-06  

## Preconditions

See [004.1-test-macros.md](./004.1-test-macros.md) for general macro testing preconditions.

Additionally:
- Account 2208 Tax liabilities (provisions) must exist (created in test 001)
- Account 8900 Direct taxes (legal entities) must exist (created in test 001)
- Account 1020 Bank Account must exist
- Partner P00000006 Canton Vaud Tax Authority must exist
- Test 004.8 TaxProvision must have been run (creating a 50.00 CHF provision in account 2208)

## Test Objective

Verify that the TaxPayment macro correctly creates a transaction to pay the tax authority, handling the case where the actual tax bill differs from the provisioned amount.

The test will validate:
- TaxPayment macro parameter form with 6 parameters
- Arithmetic expression evaluation (`{actual_amount - provision_amount}`)
- Three-entry transaction creation (liability debit, expense adjustment, bank credit)
- Scenario where actual tax > provisioned tax (additional expense recorded)
- Automatic TaxPayment tag

## Arithmetic Expression Evaluation

The TaxPayment macro template contains the arithmetic expression `{actual_amount - provision_amount}`:
- When actual = 55.00 and provision = 50.00, the expression evaluates to 5.00
- This positive result is debited to 8900 (additional expense)
- If actual < provision, the result would be negative, reducing the expense

## Notes

- This macro handles **three scenarios**:
  1. **Actual = provision**: Only liability and bank accounts are affected (expense adjustment is 0)
  2. **Actual > provision**: Additional tax expense is recorded (tested here: 55.00 vs 50.00)
  3. **Actual < provision**: Tax expense is reduced (negative amount in 8900)
- The macro uses arithmetic expression evaluation to compute the difference
- The provision (from TaxProvision macro) is cleared, and the actual payment is recorded
- Example: Provision was CHF 50, actual bill is CHF 55
  - Debit 2208 (Tax liability): CHF 50 (clears the provision)
  - Debit 8900 (Tax expense): CHF 5 (additional expense)
  - Credit 1020 (Bank): CHF 55 (total payment)
