# Test Case 004.9: Test Macros - TaxPayment

**Feature:** Macro System - TaxPayment Macro  
**Date:** 2026-04-06  

## Preconditions

See [004.1-test-macros.md](./004.1-test-macros.md) for general macro testing preconditions.

Additionally:
- Account 2208 Tax liabilities (provisions) must exist (created in test 001)
- Account 8900 Direct taxes must exist (created in test 001)
- Account 1020 Bank Account must exist
- Partner P00000006 Canton Vaud Tax Authority must exist
- Test 003 transaction 12a/12b (direct tax bill and payment of 75.00) must have been recorded

**Note:** This test does NOT depend on test 004.8 (TaxProvision). The TaxProvision
macro is now part of test 007 (year-end closing). This test pays a tax bill that
arrives during the year, with no prior year-end tax provision. The provisioned
amount is 0, so the full actual amount is debited to the 8900 Direct taxes
expense account.

## Test Objective

Verify that the TaxPayment macro correctly creates a transaction to pay the tax authority when a tax bill arrives during the year, handling the case where no prior year-end tax provision was recorded.

The test will validate:
- TaxPayment macro parameter form with 6 parameters
- Arithmetic expression evaluation (`{actual_amount - provision_amount}`)
- Three-entry transaction creation (liability debit, expense adjustment, bank credit)
- Scenario where no prior provision exists (provision_amount = 0, full amount is expense)
- Automatic TaxPayment tag

## Arithmetic Expression Evaluation

The TaxPayment macro template contains the arithmetic expression `{actual_amount - provision_amount}`:
- When actual = 55.00 and provision = 0.00, the expression evaluates to 55.00
- This positive result is debited to 8900 (full amount as expense)
- If a prior provision existed (e.g., from test 007 TaxProvision), the expression would compute the difference

## Notes

- This macro handles **three scenarios**:
  1. **No prior provision** (provision = 0): Full actual amount is debited to 8900 as expense (tested here: 55.00 with provision 0.00)
  2. **Actual > provision**: Additional tax expense is recorded for the difference
  3. **Actual < provision**: Tax expense is reduced (negative amount in 8900)
- The macro uses arithmetic expression evaluation to compute the difference
- When a prior year-end tax provision exists (from the TaxProvision macro in test 007), the provision is cleared and only the difference is recorded as additional expense
- In this test, no prior provision exists (the TaxProvision macro is part of test 007, the year-end closing flow), so the full 55.00 is debited to 8900
- Example with no prior provision:
  - Debit 2208 (Tax liability): CHF 0 (no provision to clear)
  - Debit 8900 (Tax expense): CHF 55 (full amount as expense)
  - Credit 1020 (Bank): CHF 55 (total payment)
