# Test Case 004.8: Test Macros - TaxProvision

**Feature:** Macro System - TaxProvision Macro  
**Date:** 2026-04-06  

## Preconditions

See [004.1-test-macros.md](./004.1-test-macros.md) for general macro testing preconditions.

Additionally:
- Account 2208 Tax liabilities (provisions) must exist (created in test 001)
- Account 8900 Direct taxes (legal entities) must exist (created in test 001)
- Test 003 transaction 12 (direct tax payment of 75.00) must have been recorded

## Test Objective

Verify that the TaxProvision macro correctly creates a year-end tax provision entry that:
- Debits the direct tax expense account (8900)
- Credits the tax liability account (2208)
- Creates a liability for taxes owed but not yet paid

The test will validate:
- TaxProvision macro parameter form with 3 parameters
- Default value resolution for `{year}-12-31` placeholder
- Transaction creation that records tax expense and creates a tax liability
- Automatic YearEnd:TaxProvision tag

## Macro Under Test: TaxProvision

## Acceptance Criteria

- [ ] Parameter form displays all 3 required fields with correct types

- [ ] Default value `Tax provision for {year}` is displayed in the description field
- [ ] Required field validation works correctly
- [ ] Transaction debits direct tax expense account (increases expense)
- [ ] Transaction credits tax liability account (creates liability)
- [ ] Tag `YearEnd:TaxProvision` is automatically added
- [ ] Created transaction is properly balanced
- [ ] Account balances are updated correctly
- [ ] Balance sheet equation holds after transaction

## Notes

- This macro is used at **year-end** to record tax provisions for income and capital taxes
- It creates a liability (2208) for taxes owed but not yet paid
- The tax expense (8900) increases, reducing net profit
- The provision is later cleared by the TaxPayment macro when the actual tax bill is paid
- In this test, 75.00 of tax was already paid directly in test 003 (transaction 12)
- This provision of 50.00 represents additional tax estimated to be owed at year-end
